# DOT311 — Hafta 4: Temel Bileşenler ve Flexbox

Bu proje, React Native'in 4 temel bileşeni (`View`, `Text`, `Image`, `ScrollView`) ve `Flexbox` sayfa yerleşim kurallarını pekiştiren Karakter Profil Ekranı ödevini içerir.

## Yapılan Ödev Görevleri
1. **Dördüncü İstatistik ("Zeka")**: Can (120), Güç (45) ve Hız (30) yanına dördüncü nitelik olarak Zeka (85) eklendi ve 4 kutu Flexbox (`flex: 1`, `flexDirection: 'row'`) ile eşit oranda yerleştirildi.
2. **Yerel Görsel Kullanımı**: `assets/` klasöründeki görsel `require('./assets/icon.png')` ile ekrana yüklendi ve yuvarlak avatar olarak biçimlendirildi.
3. **`StatKutusu` Bileşeni**: İstatistik kutusu tekrar kullanılabilir bir bileşen haline getirildi (`deger`, `ad`, `renk` prop'ları ile).

## WebStorm'da Çalıştırma ve Expo Go Testi
1. WebStorm'da bu klasörü açın.
2. Terminalde:
   ```bash
   npx expo start
   ```
3. Telefonunuzdaki **Expo Go** uygulaması ile QR kodu tarayın.
